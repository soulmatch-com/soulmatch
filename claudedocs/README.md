## 🔄 Maintenance

### When Adding New Documentation

1. **Development guides** → claudedocs/
2. **Fix documentation** → claudedocs/
3. **Analysis reports** → claudedocs/
4. **Essential setup guides** → root/

### Naming Conventions

- Use UPPERCASE for major guides (MIGRATIONS.md, GAPS_ANALYSIS.md)
- Use descriptive names (admin-login-fix.md, not fix.md)
- Include dates in summaries when relevant

### Keep Updated

When implementing new features:
1. Update PROJECT_HISTORY.md
2. Update GAPS_ANALYSIS.md (remove resolved gaps)
3. Create feature-specific guides in claudedocs/
4. Update this README.md index
